# Real-Time Systems

Exam projects for the **Real-Time Systems Design and Development** course (PSSTR), Bachelor's Degree in Computer Engineering, University of Naples Federico II.

Group project: Luciano Vitale, Matteo Zazzaro, Gianluca Tuccillo, Carlo Ruzzon.

> **Note**: university projects from 2023, built for teaching purposes (concurrent/real-time programming in C on Linux with POSIX, and on FreeRTOS). They do not reflect modern production development practices: today, more recent toolchains and frameworks would be used for real-time embedded systems. The application code has been kept faithful to the original exam version; only Docker and small infrastructure fixes were added to make it easy to run.

## Projects

### [SistemaABS/](SistemaABS/)
Simulation of an ABS (Anti-lock Braking System) across two independent wheels, in C/POSIX: `plant`/`controller` processes for each wheel, communication via POSIX message queues, real-time scheduling (`SCHED_FIFO`), diagnostics via a polling server. ~2100 lines of code.

**Runs in Docker** (see the [project README](SistemaABS/README.md) for details):
```bash
cd SistemaABS
docker build -t sistema-abs .
docker run -d --name abs --cap-add=sys_nice sistema-abs
docker exec abs ./reference 50
docker exec abs ./DIAG
```

### [RiconoscitoreSequenza/](RiconoscitoreSequenza/) (Sequence Recognizer)
Recognizer for a bit sequence generated by 3 independent periodic tasks, in two versions:

- **[C-POSIX/](RiconoscitoreSequenza/C-POSIX/)** — Linux/pthread version, **runs in Docker**:
  ```bash
  cd RiconoscitoreSequenza/C-POSIX
  docker build -t riconoscitore .
  docker run -it --rm --cap-add=sys_nice riconoscitore
  # press 'q' + enter to quit
  ```
- **[FreeRTOS/](RiconoscitoreSequenza/FreeRTOS/)** — the final version submitted for the exam (HW2), based on FreeRTOS tasks. **Not containerized**: the project targets the FreeRTOS-Windows simulator and requires the full FreeRTOS kernel to build; included here for reference/reading only.

### [ContatoreOttale/](ContatoreOttale/) (Octal Counter)
FreeRTOS exercise implementing a modulo-8 (octal) counter managed by multiple periodic tasks with mutex-based mutual exclusion, plus a "Polling Server" task that prints its contents on request. **Not containerized**, same limitation as the FreeRTOS sequence recognizer (Windows simulator, kernel not included).
